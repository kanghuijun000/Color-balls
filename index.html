COLOR-BALLS GUIDE
게임 설명서

게임의 목표와 규칙, 난이도별 변화, 상점 아이템의 구매와 사용법을 확인해 봐.

1. 게임 목표와 조작

내 공은 시작할 때 무작위 색으로 정해져. 화면을 터치하거나 마우스로 움직여 내 공을 조종하고, 같은 색 공을 맞혀 점수와 골드를 모으면서 오래 생존하는 것이 목표야.

  • 같은 색 공에 닿으면 공을 먹고 점수를 얻으며 골드 1개를 받아.
  • 다른 색 공에 닿으면 생명이 1개 줄어들어. 생명은 총 3개이고 모두 잃으면 게임이 끝나.
  • 공을 연속으로 먹으면 콤보가 쌓여 점수 배수가 올라가. 다른 색 공에 맞으면 콤보가 초기화돼.
  • 생존 시간이 길어질수록 기본 획득 점수와 공의 속도가 증가해.

2. 난이도별 규칙

시작 화면의 난이도 버튼을 눌러 EASY → NORMAL → HARD → EXTREME 순서로 변경할 수 있어. 난이도는 공의 등장 간격과 이동 속도, 추가 공 등장 확률에 영향을 줘.

EASY · 쉬움공이 비교적 천천히 등장하고 이동 속도도 낮아. 추가 공이 나올 확률도 가장 낮아서 조작과 규칙을 익히기 좋아.
NORMAL · 보통등장 간격과 이동 속도가 쉬움보다 빨라지고, 시간이 지나면 추가 공이 등장할 가능성도 조금 높아져.
HARD · 어려움공이 더 빠르게 접근하고 등장 간격도 짧아져. 추가 공 등장 확률이 높아 여러 공의 움직임을 동시에 살펴야 해.
EXTREME · 극한공이 가장 자주, 빠르게 등장하고 추가 공도 많이 나와. 시간이 흐를수록 공의 속도와 밀도가 서서히 높아져 순간적인 회피 판단이 중요해.

모든 난이도에서 생명은 3개로 시작하고, 같은 색 공을 먹는 기본 규칙은 같아.

3. 점수와 골드

  • 같은 색 공을 먹을 때 기본 점수를 얻고, 생존 시간이 길수록 기본 점수가 조금씩 높아져.
  • 콤보가 올라가면 점수 배수가 증가해. 콤보 배수는 최대 12배야.
  • 같은 색 공을 먹을 때마다 골드 1개를 획득해. 골드는 게임 중 상점에서 아이템을 사는 데 사용해.
  • 게임이 끝나면 이번 점수와 최고 점수, 생존 시간, 먹은 공 수를 확인할 수 있어.

4. 아이템 구매와 사용

시작 화면의 상점 버튼을 눌러 아이템을 구매해. 각 스킬은 종류별 최대 3개까지 보유할 수 있고, 구매할 때 골드 30개가 필요해. 구매 버튼을 누른 뒤 확인을 선택하면 골드가 차감되고 스킬이 추가돼.

  • 🛡️ 3초 무적: 게임 중 방패 버튼을 누르면 3초 동안 공에 맞아도 생명이 줄지 않아.
  • 🐢 5초 슬로우: 거북이 버튼을 누르면 5초 동안 모든 공의 이동 속도가 50%로 낮아져.
  • 스킬을 사용하면 해당 스킬은 1개 소모되고, 다음 사용까지 5초의 쿨타임이 있어. 보유 수가 없거나 쿨타임 중이면 사용할 수 없어.
  • 컴퓨터에서는 키보드 1번으로 첫 번째 스킬, 2번으로 두 번째 스킬을 사용할 수도 있어.

5. 일시정지와 종료

게임 화면의 Ⅱ 버튼으로 일시정지할 수 있어. 다시 시작을 누르면 3초 카운트다운 후 이어지고, 나가기를 선택하면 시작 화면으로 돌아가. 게임 오버 화면의 다시 플레이로 재도전하거나 나가기로 시작 화면에 돌아올 수 있어.

6. 멀티플레이 규칙

  • 친구와 플레이에서 방을 만들거나 6자리 방 코드로 참가할 수 있고, 최대 4명이 함께할 수 있어.
  • 각 참가자는 서로 다른 공 색상을 선택해. 방장만 게임 모드와 난이도를 바꾸고 게임을 시작할 수 있어.
  • 협동 생존에서는 함께 살아남는 것이 목표이고, 최후의 생존자 모드에서는 마지막까지 살아남는 것이 목표야.
  • 멀티플레이 중에는 상점 스킬 아이템을 사용할 수 없어. 스킬 버튼과 키보드 1·2 단축키도 비활성화돼.
  • 게임 도중 연결이 끊기면 잠시 재연결을 기다려. 제한 시간 안에 돌아오지 않은 참가자는 경기에서 제외될 수 있어.
  • 경기가 끝나면 참가자들이 대기실로 돌아온 뒤 방장이 다음 경기를 시작할 수 있어. 대기실을 나가려면 ‘대기실 나가기’를 눌러.
